# LotVPN

Сайт оплаты и выдачи ключей VPN из панели 3x-ui. Вход только по почте. После уведомления Platega сервер создаёт нового клиента или продлевает выбранный ключ. Имя клиента в панели — эта почта; второй ключ той же почты получает суффикс `+2`. При открытии кабинета срок читается из панели: подписка показывается как доступная, закончившаяся, выключенная или отсутствующая.

В папке проекта:

- `install.sh` ставит Node.js, зависимости и службу, затем создаёт `.env`. Повторный запуск с `start` поднимает сайт.
- `page.html` внешний вид сайта: разметка, стили и скрипт в одном файле. Его можно менять, сервер при этом не трогать.
- `server.mjs` вход по почте, Platega, панель 3x-ui и база. Отдаёт `page.html` и данные для него. При старте читает соседний `.env`.
- `package.json` список зависимостей и команды `npm run setup`, `npm start`.
- `package-lock.json` точные версии этих зависимостей.
- `.gitignore` не даёт закоммитить `.env` и `node_modules`.
- `cursor-app.json` просит у площадки Cursor свою Postgres. На своём сервере не используется.
- `.env` появляется после `./install.sh` и хранит пароли рядом с кодом. В git его нет.

На сервере, в этой папке:

```bash
./install.sh
nano .env
./install.sh start
```

`./install.sh start` от root ставит Caddy. Сайт открывается как `https://адрес-сервера` на порту 443, а сам Node остаётся на `127.0.0.1:3000`. Адрес берётся из `SITE_HOST`. Если строка пустая, скрипт подставляет публичный IPv4 и домен `nip.io`. Для сертификата должны быть открыты порты 80 и 443.

Без `DATABASE_URL` пользователи и ключи живут в памяти процесса и пропадают при перезапуске. Настоящие платежи включаются, когда в `.env` заданы `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET` и панель вместе с `XUI_INBOUND_ID`. Пока Platega не задана, кнопка «Провести демо-оплату» деньги не списывает и создаёт настоящего клиента 3x-ui с именем из почты. Ссылку demo.invalid эта кнопка больше не выдаёт. Уже выданные ключи со старым именем `lot…` при следующем открытии кабинета переименовываются в почту, если это имя в панели свободно. Почта для входа никуда не отправляется. `SMTP_*` нужен только если после оплаты надо ещё и прислать ключ письмом.

Цены меняются на странице `/admin`. В `ADMIN_EMAIL` укажите почту, с которой входите на сайт, и перезапустите его. Ссылка «Тарифы» появится в шапке. Там же виден список счетов: если Platega списала деньги, а ключа нет, у счёта есть кнопка «Выдать ключ». Если у панели самоподписанный сертификат, добавьте `XUI_INSECURE_TLS=1`.

В кабинете Platega, Настройки → Callback URLs, укажите `https://ваш-домен/api/platega/callback`. После `./install.sh start` это тот же адрес, по которому открывается сайт. Способ оплаты задаёт `PLATEGA_PAYMENT_METHOD`: 2 это СБП, 11 карты, 12 международные карты, 13 криптовалюта, 14 SberPay. Способ должен быть подключён в магазине.

Тарифы при первом запуске этой версии: 1 месяц за 150 ₽, 2 месяца за 300 ₽, 3 месяца за 430 ₽. Одна подписка рассчитана на 4 устройства, трафик без отдельного лимита. Старые тарифы на уже работающем сайте заменяются один раз, при первом старте после обновления. Дальше цены снова меняются на странице `/admin`. Политика конфиденциальности открывается по адресу `/privacy`, пользовательское соглашение — по `/terms`. Поддержка: Telegram @serkazvp. В запрос Platega уходит почта покупателя в `metadata.user_email`. Ссылка подписки берёт порт из `XUI_SUB_BASE_URL`, а путь — из адреса панели: если панель открывается как `https://сервер:порт/tele2`, ссылка будет `https://сервер:2096/tele2/идентификатор`, а не `/sub/`. Тот же адрес попадает в QR. Уже выданные ключи обновляются при открытии кабинета.
