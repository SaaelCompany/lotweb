# Лот

Сайт оплаты и выдачи ключей VPN из панели 3x-ui. Вход только по почте: одноразовый код и ссылка, без пароля. После уведомления Робокассы сервер создаёт нового клиента или продлевает выбранный ключ.

Пока не заданы почта, Робокасса и панель, сайт работает в демонстрационном режиме: код виден на экране, оплата — учебной кнопкой, ключ помечен как образец. Настоящие платежи включаются только когда заданы все три части.

Запуск: `npm start`. Без `DATABASE_URL` данные живут в памяти процесса. У опубликованного приложения своя Postgres, схема создаётся при старте.

Почта: `SMTP_HOST`, `SMTP_PORT` (587, для 465 включается TLS), `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`.

Робокасса: `ROBOKASSA_MERCHANT_LOGIN`, `ROBOKASSA_PASSWORD1`, `ROBOKASSA_PASSWORD2`, `ROBOKASSA_HASH` (`md5` по умолчанию, либо `sha256`, `sha384`, `sha512`), `ROBOKASSA_TEST=1` для тестовых паролей. В кабинете Робокассы: Result URL `https://ваш-домен/api/robokassa/result`, Success URL `https://ваш-домен/pay/success`, Fail URL `https://ваш-домен/pay/fail`.

Панель: `XUI_BASE_URL` (вместе со скрытым путём), `XUI_API_TOKEN` или пара `XUI_USERNAME` и `XUI_PASSWORD`, `XUI_INBOUND_ID` (несколько через запятую), `XUI_SUB_BASE_URL` (например `https://vpn.example.com:2096/sub`), `XUI_FLOW` (по умолчанию `xtls-rprx-vision`, `none` убирает flow).

Тарифы: 30 дней за 249 ₽, 90 дней за 599 ₽, 180 дней за 999 ₽, трафик без лимита.
